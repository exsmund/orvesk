# Промпты и история генерации

Здесь хранятся запросы, параметры и сведения о происхождении иллюстраций. Подкаталоги сохраняют названия серий. Исторические ссылки в метаданных могут указывать на удалённые исходники; они описывают состояние на момент генерации.

- Готовые игровые изображения: `../public/`.
- Художественные эталоны: `../refs/`.
- Правила иллюстраций: `../docs/ART_DIRECTION.md` и `../docs/ITEM_ART_DIRECTION.md`.
- `transparent-v2/plan.json` также используется страницей проверки прозрачных изображений.
- Генератор SVG-текстур вынесен в `../browser/scripts/generate-item-textures.py`. Пример безопасной генерации в отдельную папку: `python3 browser/scripts/generate-item-textures.py --out /tmp/duelyant-item-textures`. Скрипт создаёт три SVG; в игру они попадают только после отдельного копирования в `browser/public/ui/`.
