# Стартовый пейзаж

Ассет: `public/ui/start-landscape-v1.png`. Сгенерирован встроенным imagegen, 22 сентября 2026. Стиль — `ART_DIRECTION.md`, визуальный ориентир — `refs/image2.png` (материалы и свет, без переноса портрета и рамки).

Промпт: широкая готическая фэнтезийная иллюстрация для фона главного меню «Дуэлянт». Старая каменная дорога через туманную горную долину к разрушенной цитадели; скалы по краям, тусклый рассвет слева сверху. Скульптурный объём, состаренный камень, мелкая зернистая фактура, глубокая светотень. Уголь, графит, приглушённый оливковый мох, слоновая кость, немного старой бронзы. Детали по бокам и в верхней трети, спокойный тёмный центр для меню. Композиция должна работать при вертикальном центральном кадрировании на телефоне. На весь кадр, без текста, интерфейса, рамки, людей, логотипов и водяных знаков; без неона, насыщенных цветов, фотографии и крупных мазков.
