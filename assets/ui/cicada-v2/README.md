# Фон карточек: принцип цикад, v2

Три процедурных SVG вместо повторения исходной фотографии кожи:

- `item-grain-v2.svg`: мелкое зерно, период 251 px, периодический SVG-шум `stitchTiles="stitch"`.
- `item-patina-v2.svg`: слабые пятна патины, период 263 px, отдельный периодический шум.
- `item-scuffs-v2.svg`: редкие полупрозрачные царапины, период 293 px. Штрихи дублируются через границы тайла в обеих осях, включая углы.

Текстурные слои повторяются с разными смещениями. Их общий период — 19 341 809 CSS px по каждой оси. Цвет задаётся нижним неповторяющимся градиентом: оливковый для текущего предмета и бронзовый для сравниваемого. Масштаб текстур не зависит от длины карточки. Применяется в просмотре, сравнении и арсенале, включая недоступные предметы.

Это кодовые SVG-ассеты, без обработки старого PNG и без генеративной модели. Старый `item-card-leather-v1.png` сохранён как предыдущий вариант, в фоне карточек не используется.

Воспроизведение: `python3 assets/ui/cicada-v2/generate.py`, затем скопировать три SVG из этой папки в `public/ui/`. Стили: `src/ui-textures.css`. При изменении SVG обновить версию URL в CSS для сброса браузерного кеша.
