# Браузерная версия

Команды из `browser/`: `npm ci`, `npm run dev` (5173), `npm run storybook` (6006), `npm test`, `npm run build`, `npm run test:storybook`.

Из корня: `npm --prefix browser run dev` и аналогично для остальных команд.

Здесь находятся React-интерфейс (`src`), Express (`server`), Storybook (`stories`, `.storybook`), проверки (`tests`), TypeScript-инструменты (`scripts`), конфигурация и сборки.

Общие файлы находятся в корне:

- `../src/game` — правила игры, используемые также мобильными эталонными тестами.
- `../src/app/styles/palette.css` — палитра обоих клиентов.
- `../data` — каталоги; `../data/sessions` — существующие браузерные сохранения.
- `../public` — изображения; `../art-prompts`, `../refs`, `../docs` — общие материалы.
- Корневые `package.json`, `package-lock.json` и `tsconfig.json` содержат только общий TypeScript-инструментарий. Браузерные зависимости устанавливаются отдельно в этой папке.

Мобильные файлы не перемещены и не изменены. `npm ci` здесь устанавливает собственные зависимости браузера; существующие корневые зависимости доступны через стандартный поиск Node.js.

## Изображения

`public/` внутри этого пакета хранит 23 браузерных ассета (оформление, навигация и камни). Общие ресурсы остаются в `../public`. URL обеих групп прежние: `/ui/...`, `/terrain/...`. Vite-плагин `scripts/browser-public.ts` добавляет локальные файлы в dev и сборку, проверяя отсутствие совпадающих путей. Storybook подключает обе директории.

## Запуск

Node.js 22.13+. В директории `browser/`:

```sh
npm install
npm run dev
```

Открыть http://127.0.0.1:5173. Сервер по умолчанию слушает все интерфейсы (`0.0.0.0`); другой порт задаётся через `PORT=5174 npm run dev`. Для доступа только с этого Mac используйте `HOST=127.0.0.1 npm run dev`.

```sh
npm run lint
npm test
npm run build
npm start
```

`npm test` проверяет текущий одновременный бой, экипировку и путешествие. `npm run build` проверяет TypeScript и собирает интерфейс.

## Линтер

`npm run lint` проверяет исходники, сервер, тесты, скрипты и Storybook; предупреждения тоже завершают проверку с ошибкой. `npm run lint:fix` применяет доступные автоматические исправления. Остальные замечания исправляются вручную.

Конфигурация в `eslint.config.js`: рекомендованные правила ESLint, TypeScript ESLint и React Hooks, а также правила React Refresh для Vite. Генерируемые истории, сборки и сохранения исключены. Неиспользуемые поля при отделении через object rest разрешены: так из публичного состояния удаляются скрытые действия противника. Линтер не заменяет проверку типов (`npm run check`) и тесты.

## Форматирование

Prettier использует стандартные настройки: отступ в 2 пробела, двойные кавычки, точки с запятой и ширина строки 80 символов. Отступ явно закреплён в `.prettierrc.json`, остальные параметры остаются стандартными. Версия форматтера зафиксирована в `package.json`.

- `npm run format` — отформатировать браузерный пакет.
- `npm run format:check` — проверить форматирование без изменения файлов.

`eslint-config-prettier` отключает конфликтующие правила оформления ESLint. Генерируемые истории, сборки, сохранения игроков, lock-файл и исходные арт-материалы исключены через `.prettierignore`.

В бою нельзя менять экипировку или подбирать предметы. Экипировка доступна в наградах и кузнице.

## Storybook

```sh
npm run storybook
npm run test:storybook
npm run build-storybook
```

Адрес: http://127.0.0.1:6006. У компонентов соседние истории с контролами; дерево повторяет структуру `src`. Каталоги экипировки, палитры и экспериментальные прототипы остаются в `stories`. Истории не переопределяют стили игровых компонентов. Компонент `Text` и CSS-палитра задают типографику и цвета.

## Структура интерфейса

`src/main.tsx` — React-вход; `src/app/App` — состояние и экраны; `src/features` — интерфейс по областям; `src/shared/ui` — переиспользуемые контролы. CSS и истории находятся рядом с компонентами. Общие правила без React импортируются из `../src/game`.

Клик по клетке открывает попап; снятие своей фигуры — перетаскиванием за поле. `BattleWorkspace` удерживает поле на месте между фазами боя.

## Генерация текстур

`python3 scripts/generate-item-textures.py --out /tmp/duelyant-item-textures` создаёт три SVG в отдельной папке. После проверки их можно перенести в `public/ui/`.
