# Герои Орвеска

Рабочая директория: `/Users/exsmund/Projects/duelyant-v2`.

## Структура

- `src/app/` — сборка приложения; `src/game/` — общие правила без UI; `src/features/` — интерфейсы по областям со стилями рядом; `src/shared/ui/` — общие контролы и модалки. Подробная карта — в README.
- Не добавлять новые предметные модули в корень `src`; не импортировать React, CSS и клиентское хранилище из `src/game`.

## Разработка

- Локальная браузерная игра, TypeScript во всех слоях. React + Vite, Express, JSON-файлы. Не заменять файловую базу внешним сервисом без запроса пользователя.
- Текущий бой в `src/game/combat/reaction-engine.ts`, фигуры в `src/game/combat/reaction-rules.ts`/`src/game/combat/board.ts`, общие формулы в `src/game/combat/engine.ts`; предметы в `data/weapons.json` и `data/armor.json`; правила и принятые допущения в `README.md`.
- Сервер авторитетен: подготовленный слой ИИ раскрывается только игроку в роли реакции; ответ ИИ скрыт до подсчёта. Сессии в `data/sessions/`, их нельзя включать в Git или раздавать как статические файлы.
- Вкладка выбирает активного персонажа из постоянного списка этого браузера; прогресс персонажей независим. Не добавлять инвентарь. Соблюдать ограничения двух рук, требования предметов; уровень равен сумме пяти характеристик минус 7 (минимум 1). При старте путешествия фиксируется уровень героя; уровни врагов: −2/−1/−1/0/+1, минимум 1. Прокачка внутри путешествия их не меняет. Души начисляются только при выборе награды (уровень врага + 1); повышение характеристики стоит уровень героя + 2 души вне боя. Поражение обнуляет непотраченные души.
- Создание: черновик с характеристиками по 1 и 3 душами; 1 душа = +1. Сервер принимает только целые характеристики не ниже 1 с суммой 8. Готовый герой уровня 1, запас душ 0.
- Проверки после изменения механики: `npm test`, `npm run build`. Для интерфейса проверить основную последовательность в браузере и узкий экран.
- Запуск: `npm run dev`, адрес `http://127.0.0.1:5173`. Сборка: `npm run build`; запуск сборки: `npm start`.
