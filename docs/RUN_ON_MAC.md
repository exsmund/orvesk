# Запуск игры на другом Mac и телефоне в одной Wi-Fi сети

Инструкция для Mac, на котором вы можете разрешить локальные входящие подключения. На управляемом рабочем Mac настройки firewall могут быть заблокированы организацией — тогда потребуется помощь администратора.

## 1. Подключите устройства к сети

Подключите Mac и телефон к одной обычной домашней Wi-Fi сети, не к гостевой. Роутер должен разрешать устройствам общаться между собой (без client/AP isolation). Для этого сценария не нужны туннель, публичный сервер или проброс портов на роутере.

## 2. Установите Node.js и Git

Установите Node.js **22, не ниже 22.13**, с [официальной страницы Node.js 22](https://nodejs.org/en/download/archive/v22): выберите macOS Installer (.pkg). Откройте новый Терминал и проверьте:

```sh
node --version
npm --version
git --version
```

Если Git отсутствует, macOS предложит установить инструменты разработчика. Можно вызвать установку командой `xcode-select --install`, дождаться завершения и повторить `git --version`.

## 3. Скачайте репозиторий

```sh
mkdir -p ~/Projects
cd ~/Projects
git clone https://github.com/exsmund/orvesk.git
cd orvesk
npm ci
```

Если GitHub запрашивает вход, используйте аккаунт с доступом к репозиторию. Пароль аккаунта не заменяет токен GitHub; можно клонировать через GitHub Desktop и затем открыть папку репозитория в Терминале.

## 4. Соберите и запустите игру

Для игры с телефона используйте собранную версию:

```sh
npm run build
HOST=0.0.0.0 PORT=5173 npm start
```

Оставьте Терминал открытым. Сервер должен продолжать работать, а Mac — оставаться включённым и не переходить в сон. Во время игровой сессии можно запустить в отдельной вкладке Терминала `caffeinate -i` и держать крышку ноутбука открытой; остановка — Ctrl+C.

На самом Mac откройте **http://127.0.0.1:5173/**. Сначала убедитесь, что игра открывается здесь.

Для разработки вместо сборки и `npm start` можно использовать `HOST=0.0.0.0 PORT=5173 npm run dev`: изменения интерфейса будут обновляться автоматически. Запускайте только один вариант на одном порту. Просто открыть index.html или запустить статический сервер недостаточно — игре нужен Express API.

## 5. Разрешите подключение в firewall macOS

Если macOS спросит, разрешить ли Node входящие подключения, нажмите «Разрешить».

Если телефон не подключается:

1. Откройте «Системные настройки» → «Сеть» → «Брандмауэр» → «Параметры».
2. Если включена блокировка всех входящих подключений, отключите именно её. Сам брандмауэр можно оставить включённым.
3. Добавьте исполняемый файл Node в список и выберите «Разрешить входящие подключения».
4. Точный путь к используемому Node покажет команда ниже. В диалоге выбора файла нажмите Cmd+Shift+G и вставьте этот путь.

```sh
node -p 'process.execPath'
```

[Описание настроек firewall от Apple](https://support.apple.com/en-ke/guide/mac-help/-mh11783/mac). Если настройки управляются организацией, обратитесь к администратору, а не пытайтесь обойти ограничение.

## 6. Узнайте Wi-Fi адрес Mac

Откройте «Системные настройки» → «Wi-Fi» → «Подробнее» у подключённой сети → «TCP/IP». Скопируйте IPv4-адрес, например `192.168.1.50`.

Через Терминал сначала найдите интерфейс Wi-Fi:

```sh
networksetup -listallhardwareports
```

Под `Hardware Port: Wi-Fi` будет `Device: en0` или другое имя. Подставьте его в команду:

```sh
ipconfig getifaddr en0
```

Адрес `192.168.1.127`, который использовался на прежнем Mac, на новом компьютере может быть другим.

## 7. Откройте игру на телефоне

В Safari или Chrome введите адрес с IP нового Mac:

```text
http://192.168.1.50:5173/
```

Замените `192.168.1.50` на адрес из предыдущего шага. Используйте **http**, а не https. На телефоне `localhost` и `127.0.0.1` обозначают сам телефон, а `0.0.0.0` — адрес привязки сервера, не адрес для браузера.

## Если не открывается

- **Не открывается даже на Mac через 127.0.0.1:** проверьте Терминал сервера. При `EADDRINUSE` порт занят; остановите прежний процесс или запустите `HOST=0.0.0.0 PORT=5174 npm start` и используйте 5174 в адресе.
- **На Mac через 127.0.0.1 работает, а через его Wi-Fi IP нет:** проверьте адрес, `HOST=0.0.0.0` и firewall.
- **На Mac через Wi-Fi IP работает, на телефоне нет:** проверьте общую сеть, гостевую сеть, изоляцию клиентов роутера, настройки VPN и прокси, которые могут блокировать локальную сеть. На рабочем устройстве согласуйте изменение управляемых настроек с администратором.
- **Перестало работать позже:** Mac мог уснуть, сервер мог остановиться или роутер выдал другой IP. Для постоянного адреса настройте DHCP reservation для Mac на домашнем роутере.

Проверка из второго окна Терминала Mac (ожидается HTTP 200):

```sh
curl -I http://127.0.0.1:5173/
```

Проверить, что сервер слушает порт:

```sh
lsof -nP -iTCP:5173 -sTCP:LISTEN
```

При запуске с `HOST=0.0.0.0` ожидается прослушивание `*:5173`, а не только `127.0.0.1:5173`.

## Повторный запуск и обновление

Повторный запуск готовой сборки:

```sh
cd ~/Projects/orvesk
HOST=0.0.0.0 PORT=5173 npm start
```

Для обновления остановите сервер сочетанием Ctrl+C, затем:

```sh
cd ~/Projects/orvesk
git pull --ff-only
npm ci
npm run build
HOST=0.0.0.0 PORT=5173 npm start
```

## Сохранения

Состояние игры хранится на Mac в `data/sessions/`; папка создаётся автоматически и не попадает в Git. Список персонажей браузера хранится отдельно в его локальном хранилище. Новый Mac и браузер телефона не получат прежних героев автоматически. Не очищайте данные сайта, если хотите сохранить доступ к персонажам. Смена IP или порта меняет адрес сайта и его браузерное хранилище.

Для резервной копии остановите сервер и скопируйте `data/sessions/`. Одной серверной копии недостаточно для автоматического восстановления списка героев в новом браузере.
