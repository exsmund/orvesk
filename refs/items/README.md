# Эталоны иллюстраций предметов

- `dagger.png` — металл и композиция оружия.
- `buckler.png` — металл и объём щита.
- `robe.png` — ткань, складки и силуэт одежды.

PNG с настоящей прозрачностью соответствуют текущим предметам из `images/items`.

Используются вместе с [художественным направлением предметов](../../docs/ART_DIRECTION.md). Материалы, композиция и прозрачный фон соответствуют текущим требованиям. Фон интерфейса должен быть виден вокруг предмета и в просветах.

Запросы текущих изображений: [кинжал](../../art-prompts/weapons/dagger.json), [баклер](../../art-prompts/shields/buckler.json), [одежда](../../art-prompts/armor/robe.json).
