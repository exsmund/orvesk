# Эталоны иллюстраций предметов

- `dagger.png` — металл и композиция оружия.
- `buckler.png` — металл и объём щита.
- `robe.png` — ткань, складки и силуэт одежды.

Эталоны заменены прозрачными версиями 2026-09-27. Это точные копии `public/items/dagger-transparent-v2.png`, `buckler-transparent-v2.png` и `robe-transparent-v2.png` из серии PNG RGBA с настоящим прозрачным фоном.

Используются вместе с [художественным направлением предметов](../../docs/ITEM_ART_DIRECTION.md). Материалы, композиция и прозрачный фон соответствуют текущим требованиям. Фон интерфейса должен быть виден вокруг предмета и в просветах.

Точные запросы и происхождение изображений: [plan.json](../../art-prompts/transparent-v2/plan.json) и [results.json](../../art-prompts/transparent-v2/results.json).
